                                           FRAME CONTRACT (Coordinate System)

  Pipeline & Database (Z-up, metres):              Frontend Three.js (Y-up, metres):
  ┌──────────────────────────────────┐            ┌──────────────────────────────────┐
  │          Z (up/height)           │            │         Y (up/height)            │
  │            │                     │            │           │                      │
  │            │                     │            │           │                      │
  │      X ────┼──── (east)          │            │    X ─────┼───── (east)          │
  │           /                      │            │          /                       │
  │          Y (north)               │            │         Z (depth/into screen)    │
  │                                  │            │                                  │
  │ SRID 0 (Cartesian, Z-up)         │            │ Converted via rotation.x = -90°  │
  │ Ground at z = 0                  │            │                                  │
  │ Heights = positive Z             │            │ ✓ Frame Contract: All splats,    │
  │ Scale factor ∈ (0, ∞)            │            │   meshes, highlights, ghosts    │
  │                                  │            │   are children of sceneRoot.    │
  └──────────────────────────────────┘            │   NO OTHER COMPONENT ROTATES.  │
  │                                               └──────────────────────────────────┘

  │ Rotate to Z-up, set z_min = 0                 │
